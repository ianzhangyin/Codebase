# 猫猫云

A responsive multi-cloud services landing page for https://cn2cloud.cc/.

The site presents cloud resource selection, purchasing assistance, deployment, migration, and usage guidance for Alibaba Cloud, AWS, Google Cloud, and Azure. It is a static marketing site and does not process orders or represent any provider's official position. Authorization, procurement, pricing, and service scope must be confirmed in writing for each engagement.

## Run locally

Open `index.html` in a browser. The page uses plain HTML, CSS, JavaScript, and a local SVG illustration; no build step is required.
