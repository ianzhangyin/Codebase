# 毛茸茸 API

A responsive, static landing page concept for **毛茸茸 API**, informed by a passive REA review of the public homepage at https://yunwu.ai/.

## Run locally

Open `index.html` in a browser. The page uses plain HTML, CSS, and JavaScript; no build step is required.

## Scope

This project recreates a high-level landing page structure with an original visual treatment and the 毛茸茸 API name. It does not copy the source site's bundled application code, tracking scripts, logos, or backend behavior. Console access, billing, authentication, and API calls are not connected.
